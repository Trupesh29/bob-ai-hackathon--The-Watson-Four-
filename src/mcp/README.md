# PortFlow AI — MCP Server

> **IBM Bobathon 2026 — Track AI, Problem L1**

## Purpose

The PortFlow MCP server exposes three read-only tools that IBM Bob can call
to explain PortFlow API results in plain language inside the IBM Bob IDE.

All tools fetch from the running FastAPI backend and format the response as
human-readable text.  No writes occur — the server is entirely read-only.

---

## Tools

| Tool | Description |
|---|---|
| `get_risk_explanation` | Plain-language summary of the 72-hour congestion risk forecast |
| `get_plan_summary` | Runs the CP-SAT optimizer and explains the assignment plan |
| `get_waiting_time_context` | Explains the waiting-time forecast for all scheduled vessels |

---

## Quick Start

```bash
# From src/mcp/ — install dependencies and build
npm install
npm run build

# Verify
node build/index.js --help   # prints version info and exits
```

---

## Configuration

| Environment Variable | Default | Description |
|---|---|---|
| `PORTFLOW_API_BASE` | `http://localhost:8000/api/v1` | FastAPI backend base URL |

---

## Usage in IBM Bob

Register the server in your workspace `mcp.json`:

```json
{
  "mcpServers": {
    "portflow": {
      "command": "node",
      "args": ["<absolute-path-to>/src/mcp/build/index.js"],
      "env": {
        "PORTFLOW_API_BASE": "http://localhost:8000/api/v1"
      }
    }
  }
}
```

Then ask Bob:

- "Use get_risk_explanation to explain port congestion for FKPFL."
- "Use get_plan_summary to show me the 72-hour operations plan."
- "Use get_waiting_time_context to explain vessel delays."

---

## Data Policy

All data returned by these tools is:

- **Synthetic** — generated by `src/data/generator.py` with `seed=2026`
- **Labelled** — every response includes an explicit synthetic-data warning
- **Read-only** — no writes to the database or API occur

---

## Limitations

1. The FastAPI backend must be running for tools to succeed.
2. All figures are from synthetic data — not validated for real-world use.
3. `get_plan_summary` runs the optimizer on every call (no caching).
4. Human approval is required before acting on any plan output.
