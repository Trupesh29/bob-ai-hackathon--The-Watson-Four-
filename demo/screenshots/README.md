# PortFlow AI — Screenshots

This directory will contain screenshots of the working application.

## Required Screenshots (minimum 3)

1. **Congestion Dashboard** — showing vessel risk scores and the 72-hour
   prediction heatmap or time-series chart.

2. **Plan Comparison View** — showing the baseline (FCFS) plan vs the
   optimised plan side-by-side, with waiting-time savings highlighted.

3. **Approval Gate** — showing the supervisor's Approve / Reject action
   and the IBM Bob explanation panel.

## Optional Screenshots

- ML model training output / validation metrics
- OR-Tools CP-SAT solver output log
- IBM Bob IDE session working on PortFlow AI code
- MCP server explanation response in IBM Bob
